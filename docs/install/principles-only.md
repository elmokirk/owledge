# Principles-only recipe

Use this when an existing agent system needs the Owledge operating rules but
does not yet need local validation, indexes, or durable kit files.

## Prerequisites

None. Run it from the existing project or vault; no package, checkout, plugin,
or global environment setting is required.

## Apply

Give the agent this bounded instruction:

```text
Use Owledge principles only. Keep existing files unchanged. Treat Markdown as
canonical memory, write evidence-linked plans and handoffs, keep raw sessions
private, and promote only reviewed memory.
```

## Result and limits

Host-project writes: **zero**. Install footprint: **N/A**. The result is a
shared operating rule, not a local Owledge installation. Add the
[project-local kit](project.md) only when the project needs durable local
artifacts or deterministic validation.
