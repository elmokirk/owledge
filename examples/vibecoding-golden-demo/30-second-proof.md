# 30-second Owledge proof

**Before:** a second agent has to reconstruct an unfinished request from chat.

**After:** the next agent reads a scoped feature request, its evidence, and a
handoff from the project itself.

| The next agent needs | Durable project artifact |
| --- | --- |
| What to change | `.owledge/canonical/filter-request.md` |
| What was checked | `.owledge/evidence/filter-request-check.md` |
| What to do next | `.owledge/handoffs/filter-request-resume.md` |

**Success signal:** all three links are present before the next agent starts.

This is a read-only example. Reading it writes **zero files**, requires no
account or API key, and does not claim that a runtime, plugin, or remote Hub is
installed.
