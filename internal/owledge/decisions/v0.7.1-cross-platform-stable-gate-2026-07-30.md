# v0.7.1 cross-platform verification gate placement

## Decision

The v0.7.1 development ticket `OW-071-10` may proceed after its supported
Windows wheel-only package smoke and independent review. Actual macOS and Linux
execution remains required, but moves to the Stable/GA release gate in
`OW-100-09` rather than blocking v0.7.1 development work.

## Rationale

The product owner explicitly deferred macOS and Linux validation to the stable
version. This preserves incremental delivery while retaining a hard,
evidence-backed cross-platform requirement before a stable product claim.

## Constraints

- The three-OS CI fixture remains tracked; it is not removed or weakened.
- v0.7.1 must not claim verified macOS or Linux package support.
- A branch push alone does not run the current workflow: `.github/workflows/ci.yml`
  runs on `main` pushes and pull requests. A PR or equivalent authorized CI run
  is required to collect the deferred evidence.
- `OW-100-09` must record clean Windows, macOS, and Linux artifact-install
  outcomes before `G-100-GA` can pass.

## Reversibility

The owner may restore cross-platform execution as a v0.7.1 blocker by amending
this decision and returning `OW-071-10` to an active acceptance state. No
runtime interface or package behavior is changed by this decision.
