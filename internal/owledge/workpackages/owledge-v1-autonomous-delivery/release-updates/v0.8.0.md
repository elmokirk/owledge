# Owledge v0.8.0 Feature Update

## Feature Update

v0.8.0 delivers the portable control-plane foundation: versioned contracts and settings, MVP/roadmap routing, bounded resume and gate sidecars, small-model profiles, retrieval projection, Research-Memory recall, copy-only RUN-STATE sharding, and native Claude-compatible context hooks. The public CLI contract is documented and the package/version manifests are aligned at `0.8.0`.

## User Benefits and Adoption Impact

Projects can keep an MVP cutline while routing out-of-scope ideas into a durable roadmap, resume with bounded context, use explicit small-model retries, and retrieve scoped Research Memory before external work. Host projects receive discoverable local skills and non-overwriting native-hook wiring.
