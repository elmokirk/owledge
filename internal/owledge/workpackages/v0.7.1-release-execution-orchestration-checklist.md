## Agent Rules

- Implementation agents receive one ticket and non-overlapping path claim.
- Review agents remain read-only and return P0-P3 evidence, score, and verdict.
- Ticket workers create one cohesive commit and manifest in isolated branches;
  fresh-context QA reviews that exact commit. The orchestrator owns central
  state, README/index integration, merges, evidence-only commits, release
  artifacts, and the final alignment update.
- No agent may tag, publish, push, merge, or start v0.8.0.
