# v0.7.1 Phase 0 Independent Review Synthesis

## Subject and Review Question

Can the current uncommitted foundation diff be frozen and used as the clean
base for `OW-071-01`?

## Review Lanes

| Lane | Score | Verdict |
| --- | ---: | --- |
| Release Engineering / Git Hygiene | 62 | block |
| Staff Engineering / Control Plane | 76 | revise |
| Security / Product Truth / Blindspot | 74 | revise |

Consensus: no P0 was found, but the foundation freeze is blocked until every
P1 below is fixed and independently rechecked.

## Accepted P1 Findings

1. Dogfood validation/exports can pass while scanning zero intended records.
2. True legacy manifests do not gain additive `.agents/skills` inventory.
3. Wheel data-files omit the declared `owledge-autonomous-delivery` host skill.
4. Generated evidence and a plan command contain local absolute paths.
5. Finalization evidence predates the complete source and is not bound to a
   clean tested commit.
6. `W-071-A` violates ticket dependencies; validator lacks topology checks.
7. `OW-071-01` lacks exact source, path, state, validator, and fixture
   contracts.
8. Worker-commit/evidence rules conflict with orchestrator-only commit wording.
9. RUN-STATE did not record the user's orchestration authorization or Phase 0.

## Accepted P2 Corrections

- Fix `tests/unit/test_validate_v1_delivery_plan.py` path/command in RUN-STATE.
- Keep the new orchestration plan/checklist `unreviewed` until re-review.
- Split Phase-0 source and generated-evidence commits.
- Execute Phase 071-A2/A3/A4 sequentially because their tool, test, and
  release-gate claims overlap; do not dispatch them in parallel.

does not block the foundation commit only while public guidance remains

## Clean-SHA Gate Attempt 1

The first finalization run against clean source commit `85f3a4d` passed `36/38`
gates and correctly stopped promotion. It exposed two additional gate defects:

- the sensitive scanner classified the exact GitHub Actions OIDC permission
  `id-token: write` as a secret value;
- the evidence privacy gate inspected the prior finalization report before the
  current report was persisted, and nested JSON-escaped paths required an
  additional sanitizer form.

Both are tracked as `F-071-10` and `F-071-11`. The fixes keep generic
token-value detection intact, add a real-token negative fixture, sanitize
native and JSON-escaped roots, scan all other exports before report
persistence, and verify the complete generated evidence set after persistence.
Attempt-1 exports remain stale and are excluded from the source-fix commit.

## Phase 0 Promotion Reflection

Clean-SHA attempt 2 passed `38/38` against
`5d6c4339432b4ccc4b4eec09004b6f80c7846f44`; every quality-ratchet dimension
scored `100`, and the post-write privacy scan passed. The integration branch is
`codex/v071-integration`.

Decision: promote the Foundation and start only `OW-071-01`. Keep
`OW-071-02`, `OW-071-03`, and `OW-071-13` serial and blocked until the live
work register is accepted. Keep the HTTP boundary finding `F-071-09` open for
`OW-071-13`; do not publish any remote/team-server claim.

The durable reflection is intentionally committed before one final replay of
the 38 gates. This ensures the committed Phase-0 evidence describes the final
reflected control-plane state rather than the pre-reflection source.
